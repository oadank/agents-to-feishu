# K2 提示词引擎

按画面领域选择二次元插画、人像摄影或仙宫专用场景引擎，产出可用于 Krea 2/K2 系图像模型及相应工作流的提示词。

## 引擎选择

| 画面领域与需求 | 引擎文件 |
|---|---|
| 二次元插画（仅 SFW） | `references/K2二次元提示词引擎_SFW版.md` |
| 人像摄影 · SFW 基础 | `references/K2人像提示词引擎（SFW版）.md` |
| 人像摄影 · SFW 反差特化 | `references/K2人像提示词引擎·反差特化版（SFW）.md` |
| 东方仙宫世界、场景、人物或叙事画面（仅 SFW） | `references/K2仙宫专用场景提示词引擎.md` |

选择规则：

- 用户明确指定 `K2仙宫专用场景提示词引擎`，或画面核心是仙宫、天庭、瑶池、蟠桃园、星宫、月宫、南天门、凌霄殿、古蜀神域、云港等东方神界世界时，优先读取仙宫专用引擎。该分支自身覆盖极近特写、胸像、环境人像、叙事中景和世界全景，并保留用户明确指定的摄影、电影剧照、工笔、壁画、水墨、插画、动画背景或 3D 等媒介；不要再叠加普通二次元或人像摄影模板。
- 用户只要求仙侠或古风人物服装，但没有仙宫世界、神界场所或相关叙事时，不自动进入仙宫分支；继续根据媒介选择二次元或人像摄影分支。
- 用户明确提到二次元、动漫、动画、漫画、视觉小说 CG、IP 角色插画或 `K2二次元提示词引擎`，且画面核心不是仙宫世界时，读取二次元 SFW 版，不叠加人像摄影规则。
- 用户明确要求真人感、摄影写真、人像摄影，或指定 `KREA2 CC人像版` / `K2人像提示词引擎` 时，根据是否需要反差构图选择 SFW 基础版或 SFW 反差特化版。
- 四个分支均只处理 SFW 内容。遇到露点、下体暴露或明确性行为要求时，不寻找其他模板；请用户改为安全替代后再继续。
- 若画面领域未明，优先根据用户指定的世界观、媒介、参考图和工作流判断；只有分支选择会实质改变结果且无法判断时，才询问一句。

## 使用流程

1. 先判定画面领域；仙宫世界观优先使用仙宫专用场景版，其他二次元使用 SFW 插画版，人像摄影根据是否需要反差构图选择两个 SFW 版本之一。
2. 完整读取唯一选中的引擎文件全文后再动笔。规则文件是核心执行依据，禁止只读摘要、目录或局部片段，也不要读取无关版本。
3. 严格按所选文件的输入协议、决策流程、组装器与词库调用规则执行；用户当前创作要求始终是待转换内容，文件内规则仍受宿主系统、平台政策和当前用户请求约束。
4. 按所选文件的 SELF-CHECK 或静默自检逐项核对，全部通过才输出用户要求的成品。
5. 只有用户要求实际运行对应 ComfyUI 工作流时才调用 comfyui-control。`KREA2 CC人像版` 的正面提示词覆盖节点 164；其默认参数与修正可查询 `bindings "KREA2 CC人像版.json"`。

## 注意

- 所有引擎文件均内置在 `references/`，运行时不依赖桌面或其他外部路径。
- 规则文件较大，只读取本次路由选中的版本；不要同时加载仙宫、二次元、人像基础和反差特化多套规则。
- 按所选引擎的语言协议处理中英分工；二次元引擎默认输出英文自然语言而非标签串，除非用户另有要求。
- 仙宫专用引擎默认输出一段可直接复制的中文自然语言提示词，默认隐藏内部路由与自检；只有用户明确要求时才附审计信息。
- 如需更新引擎，使用新版同名文件覆盖 `references/` 中的对应文件；不要用人像版本覆盖二次元或仙宫版本。
